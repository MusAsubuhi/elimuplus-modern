# /images — what needs to go here

This folder is currently empty. Every page on the site is built to work
without these files — every spot that needs a photo is now a raw, obvious
red-dashed placeholder box (or a red "Needs image" tag on hero banners),
so it's clear at a glance where a real photo still needs to go.

See **needed-images.txt** in this folder for the full list of exact
filenames, what each one is used for, and where.

Drop real photos in using those exact filenames, then ask Claude Code to
swap the matching raw placeholder for a real `<img>` tag.

## Guidelines

- Real photos only — no stock imagery, nothing staged or studio-lit.
- No images of children in poverty — this is a business training
  programme, not a welfare organisation.
- Compress before upload. Target well under 200KB per photo where
  possible so mobile pages stay fast on Android data connections.
