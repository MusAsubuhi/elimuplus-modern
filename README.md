# Elimu+ website

Static site (HTML, CSS, JS). Blog: see BLOG-GUIDE.md and build-blog.js.

## Biashara za Elimu+ directory and Elimu+ SACCO

- `directory.html` is generated by `node build-directory.js` from `directory-data/entries.json`. While any entry has `"sample": true` it shows a preview banner and is set to noindex, and it is not linked in the navigation or sitemap. Replace the sample entries with real, consented and host-approved ones before linking it.
- `sacco.html` is a coming-soon page (no deposits accepted). It is linked in the footer and the sitemap.
- Consent forms live outside this repo, in TAG: ELIMU+ / 1. ADMINISTRATION / Legal & Compliance.
