# Elimu+ website

Static site (HTML, CSS, JS). Blog: see BLOG-GUIDE.md and build-blog.js.

## Biashara za Elimu+ directory and Elimu+ SACCO

- `directory.html` is generated by `node build-directory.js` from `directory-data/entries.json`. It is public as a "coming soon" preview: while any entry has `"sample": true` it shows a coming-soon banner with imaginary sample people and asks search engines not to index it. It is linked in the footer and listed in the sitemap. Replace the sample entries with real, consented and host-approved ones when the first listings are ready.
- `sacco.html` is a coming-soon page (no deposits accepted). It is linked in the footer and the sitemap.
- Consent forms live outside this repo, in TAG: ELIMU+ / 1. ADMINISTRATION / Legal & Compliance.
